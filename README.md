📄 Bootstrap Blog Website 

Bu proje, daha önce HTML/CSS ile hazırlanmış blog sitesinin Bootstrap kullanılarak yeniden tasarlanmış halidir. Amaç, Bootstrap’in sağladığı hazır bileşenleri ve grid sistemini kullanarak daha düzenli, modern ve responsive bir arayüz oluşturmaktır.

🎯 Projenin Amacı

Bootstrap 5 bileşenlerini uygulamalı olarak öğrenmek

Grid sistemi, kart yapısı, responsive tasarım ve navbar gibi temel öğeleri kullanmak

Önceki blog sayfasını daha profesyonel ve modern bir görünüme kavuşturmak

✔️ Uygulanan Bootstrap Özellikleri

Koyu renkli Navbar

Jumbotron / Hero alanı (Ana sayfa açıklaması için)

Grid sistem içinde düzenlenmiş Card yapıları

Tüm blog kartlarının aynı boyutta görünmesi

Mobil uyumlu, responsive tasarım

Bootstrap button, spacing, typography ve shadow sınıfları

📁 Dosyalar

index.html → Ana sayfa, jumbotron + blog kartları

post.html → Tekil blog yazısı sayfası

styles.css → Bootstrap’e ek hafif özel stiller

🛠 Kullanılan Teknolojiler

HTML5

CSS3

Bootstrap 5.3

🚀 Nasıl Çalıştırılır?

Tüm dosyaları aynı klasöre yerleştirin.

index.html dosyasını tarayıcıda açın.

Navigasyon menüsünden sayfalar arasında geçiş yapabilirsiniz.
